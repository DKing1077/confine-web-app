# PostgreSQL + Docker + Local Mac — Command Cheat Sheet

========================================================
1. DOCKER (GENERAL)
========================================================

List running containers:
docker ps

List all containers:
docker ps -a

Stop a container:
docker stop <container_name>

Start a container:
docker start <container_name>

Restart a container:
docker restart <container_name>

Enter a running container:
docker exec -it <container_name> bash

View logs:
docker logs <container_name>

Live logs:
docker logs -f <container_name>


========================================================
2. DOCKER COMPOSE (YOUR SETUP)
========================================================

Start everything:
docker-compose up

Start in background:
docker-compose up -d

Build + start:
docker-compose up --build

Stop everything:
docker-compose down

Stop without deleting containers:
docker-compose stop

Rebuild clean:
docker-compose down -v
docker-compose up --build

View logs:
docker-compose logs

View web logs only:
docker-compose logs web

Live logs:
docker-compose logs -f web


========================================================
3. POSTGRES (INSIDE DOCKER CONTAINER)
========================================================

Enter Postgres container:
docker exec -it confine-web-app-postgres-1 psql -U postgres -d test_db

List databases:
\l

Connect to database:
\c test_db

List tables:
\dt

Describe table:
\d table_name

View rows:
SELECT * FROM table_name;

View limited rows:
SELECT * FROM table_name LIMIT 10;

Count rows:
SELECT COUNT(*) FROM table_name;

Delete all rows:
DELETE FROM table_name;

Fast delete + reset IDs:
TRUNCATE TABLE table_name RESTART IDENTITY CASCADE;

Drop table:
DROP TABLE table_name;

Exit psql:
\q


========================================================
4. POSTGRES (IF INSTALLED ON MAC)
========================================================

Connect:
psql -U postgres -d test_db

List databases:
\l

List tables:
\dt

View rows:
SELECT * FROM table_name;

Delete all rows:
TRUNCATE TABLE table_name RESTART IDENTITY CASCADE;

Exit:
\q


========================================================
5. FLASK + DOCKER NETWORKING (IMPORTANT)
========================================================

Inside Docker:
- Use "postgres" as DB host
- Use "redis" as Redis host

NOT:
- localhost (wrong inside containers)

Example:
DB_HOST=postgres
REDIS_URL=redis://redis:6379/0


========================================================
6. COMMON DEBUG CHECKS
========================================================

Check containers:
docker ps

Check logs:
docker logs web

Check database connection:
docker exec -it <postgres_container> psql -U postgres


========================================================
7. KEY IDEA
========================================================

Docker = isolated environment
Compose = multi-service system
Postgres = database layer
Redis = messaging layer
Flask = API layer
Celery = background worker
